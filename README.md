# Calculator App

Simple, responsive web design, and user-friendly calculator web app, using CSS Grid, React, Bootstrap, and Sass.

Built with [Vite](https://vite.dev/) and deployed to GitHub Pages (`npm run deploy`).

![CalculatorUI](https://github.com/user-attachments/assets/2ee1feb7-feaf-4f0c-87b6-95145ed2c9a1)

## Scripts

- `npm run dev` — start the dev server
- `npm start` — same as `npm run dev` (CRA-style alias)
- `npm run build` — production build (output in `dist/`)
- `npm run preview` — preview the production build locally
- `npm test` — run tests (Vitest)
- `npm run deploy` — build and publish `dist/` to the `gh-pages` branch
